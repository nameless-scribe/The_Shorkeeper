The Shorekeeper · Personal Assistant Roadmap

从“记得”走向
“知道为什么可信”

P1 将现有长期记忆与 RAG 升级为可追溯的个人模型：事实有类型、来源、时效和冲突关系；回答可以解释用了什么，偏好变化后不再沿用冲突旧事实。

6 个阶段 3 个兼容 migration P0 真实验收可并行 P2 外部连接暂不进入

不是重写，是增量升级

现有候选确认、向量检索、文档版本和运行审计都保留。P1 只补齐缺失语义，并让各层共享同一事实状态。

✓ 已有可复用底座

  • 结构化 memory_key、重要度、Embedding 与人工管理
  • 候选置信度、确认/拒绝和防止自动恢复
  • RAG 生命周期、哈希去重、版本链与文件名引用
  • Goal / Commitment 真源与 TaskRun 审计

△ P1 要补齐的缺口

  • 同 key 更新会丢失旧事实与变化原因
  • 缺少类型、时效、敏感度、状态与替代关系
  • 来源只到会话，回答无法稳定回链
  • 本地源变化后，旧索引不会主动提示过期

可信个人事实链

任何新事实都经过同一条链路；模型不能绕过策略直接覆盖已确认事实。

01 · 采集对话、手工编辑、文档、工具、目标与承诺
02 · 标准化七类事实、置信度、敏感度、模型使用策略、有效期与稳定来源引用
03 · 策略闸门重复、补充、冲突、敏感与禁止保存内容分流
04 · 版本化active / disputed / superseded / expired / rejected
05 · 使用与回链上下文筛选、run 来源记录、回答引用和详情跳转

六步实施路线

点击阶段查看范围和出口。每一步都能单独测试、审查和停止，不把数据库、Agent、RAG 与 UI 混成一次大改。

00

先固定什么叫“正确”

建立稳定事实、偏好变化、关系推断、短期事件、敏感信息、真假冲突和来源变化样本；定义七类事实、状态机、有效期和冲突决策矩阵。

  • 建立 test:p1 入口
  • 不改变现有运行行为
  • 让后续每步都有失败样例
已完成

固定样本、受控词汇与 test:p1 已落地并通过。

01

0023 · 个人事实数据底座

扩展长期记忆和候选字段，新增 memory_sources；旧数据回填为 active/other/normal。

  • 类型、置信度、敏感度、模型使用策略与有效期
  • memory_key 改为仅 active 事实唯一
  • 状态、替代关系与稳定来源
已完成

0023 旧库回填、历史共存与双 adapter 临时库验证已通过。

02

冲突识别与用户裁决

新值不再直接覆盖同 key 旧值。先区分重复、补充与真实冲突，再让用户选择保留、替代或并存。

  • 关系、敏感、低置信和冲突必须确认
  • 替代在单一事务内完成
  • 手工编辑也进入版本化服务
已完成

冲突样本零静默覆盖；拒绝不复活；事务化版本链、重复确认和真实 Electron 三种裁决验收通过。

03

0024 · 使用来源与回答回链

只选择 active、未过期且 model_use_policy 允许的事实；把实际使用的记忆、文档、目标与承诺写入 run 上下文来源。

  • 相关度 × 重要度 × 置信度 × 新鲜度
  • 稳定 memory/document 引用标签
  • 回答引用卡片与运行详情回链
已完成

预算后来源账本、四类稳定引用、回答卡片和运行详情回链已通过自动化与 Electron 验收。

04

0025 · 本地知识新鲜度

记录来源 mtime/size/hash 与检查时间；来源变化先标记 changed，重建成功后才原子切换新版本。

  • 默认手工检查，显式开启低频同步
  • 变化、缺失、重建失败都有状态
  • 外部邮箱/云盘同步留给 P2
已完成

未变化不重复索引；changed/missing、重新定位、低频同步和旧版本保护已接入。

05

真实 Electron 与总体工程验收

覆盖记忆筛选、冲突确认、来源详情、过期状态、知识更新和运行引用；一周真实使用作为上线后的独立观察窗口持续记录。

  • test:p1 + test:p1:ui
  • P0/S2/S4/S5 与全量回归
  • 观察结论不由 mock 冒充
工程已完成

个人模型端到端闭环可用；一周观察在实际使用满周期后补录结论。

三道不可绕过的门

这是 P1 的完成标准，也是之后进入 P2 外部连接器前的安全前提。

数据兼容门

迁移只追加、不改已发布 migration；旧记忆和文档版本可读；测试仅使用临时数据库。

可信行为门

冲突不静默覆盖，敏感事实不自动注入，状态和来源由领域服务统一决定。

可解释验收门

真实 Electron 中能查看来源和冲突；真实使用证明偏好更新后不再引用旧事实。
