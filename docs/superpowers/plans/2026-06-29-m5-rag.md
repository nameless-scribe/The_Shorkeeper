# M5 RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现文档导入、向量存储与检索，使 Agent 问答能引用用户导入的 MD/TXT 文档内容；顺带完成 M3 延后的语义记忆去重。

**Architecture:** 沿用现有 **sql.js** 栈（M1 已放弃 better-sqlite3）。**sqlite-vec 扩展无法在 WASM SQLite 中加载**，因此 M5 采用 `embedding BLOB`（Float32Array）+ TypeScript 余弦相似度检索。接口层（`retriever.ts`）与存储解耦，日后若迁回原生 SQLite 可替换为 sqlite-vec 而不改上层。Embedding 走 OpenAI 兼容 `/embeddings` 端点（百炼 `text-embedding-v3` 或 `text-embedding-3-small`）。文档文件复制到 `WORKSPACE_DIR/knowledge/`，元数据与 chunk 存 SQLite。

**Tech Stack:** sql.js · OpenAI-compatible Embeddings API · Vitest · Electron IPC · React 设置页

---

## 关键约束（实施前必读）

| 项 | 决策 |
|----|------|
| 向量存储 | BLOB + JS top-K，**不用** sqlite-vec（与 sql.js 不兼容） |
| 分块 | `chunk_size=512` 字符，`overlap=64` 字符 |
| 检索 | 用户消息 embedding → top-5 chunks → `<reference>` 注入 system |
| 文件格式 | M5 仅 MD/TXT；PDF/DOCX 留 M7 |
| 规模假设 | 自用场景 <5000 chunks，线性扫描可接受（~50ms 级） |
| Embedding 成本 | 导入时按 chunk 计费；检索时每次用户消息 1 次 embedding |

`src/rag/vector.ts`:

```typescript
export function cosineSimilarity(a: Float32Array, b: Float32Array): number {
  if (a.length !== b.length || a.length === 0) return 0;
  let dot = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  const denom = Math.sqrt(normA) * Math.sqrt(normB);
  return denom === 0 ? 0 : dot / denom;
}

export function serializeEmbedding(values: number[]): Uint8Array {
  return new Uint8Array(new Float32Array(values).buffer);
}

export function deserializeEmbedding(bytes: Uint8Array): Float32Array {
  return new Float32Array(bytes.buffer, bytes.byteOffset, bytes.byteLength / 4);
}

export interface Scored<T> {
  item: T;
  score: number;
}

export function topKBySimilarity<T>(
  query: Float32Array,
  items: Array<{ data: T; embedding: Float32Array }>,
  k: number,
): Scored<T>[] {
  const scored = items.map(({ data, embedding }) => ({
    item: data,
    score: cosineSimilarity(query, embedding),
  }));
  scored.sort((a, b) => b.score - a.score);
  return scored.slice(0, k);
}
```

`src/rag/embedding.ts`:

```typescript
import { loadModelConfig } from '../models/config';

const DEFAULT_EMBEDDING_MODEL =
  process.env.EMBEDDING_MODEL?.trim() || 'text-embedding-v3';

export function getEmbeddingModel(): string {
  return DEFAULT_EMBEDDING_MODEL;
}

interface EmbeddingsResponse {
  data?: Array<{ embedding?: number[] }>;
}

export async function embedTexts(
  texts: string[],
  options?: { signal?: AbortSignal },
): Promise<number[][]> {
  const trimmed = texts.map((t) => t.trim()).filter(Boolean);
  if (!trimmed.length) return [];

  const config = loadModelConfig();
  const response = await fetch(`${config.baseUrl}/embeddings`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${config.apiKey}`,
    },
    body: JSON.stringify({
      model: DEFAULT_EMBEDDING_MODEL,
      input: trimmed,
    }),
    signal: options?.signal,
  });

  if (!response.ok) {
    const text = await response.text();
    throw new Error(`Embeddings API ${response.status}: ${text}`);
  }

  const data = (await response.json()) as EmbeddingsResponse;
  const vectors = data.data?.map((d) => d.embedding).filter(Boolean) as number[][];
  if (!vectors?.length || vectors.length !== trimmed.length) {
    throw new Error('Embeddings API 返回格式异常');
  }
  return vectors;
}

export async function embedText(text: string, signal?: AbortSignal): Promise<number[]> {
  const [vec] = await embedTexts([text], { signal });
  return vec;
}
```

`src/rag/chunker.ts`:

```typescript
export const CHUNK_SIZE = 512;
export const CHUNK_OVERLAP = 64;

export function splitTextIntoChunks(
  text: string,
  chunkSize = CHUNK_SIZE,
  overlap = CHUNK_OVERLAP,
): string[] {
  const normalized = text.replace(/\r\n/g, '\n').trim();
  if (!normalized) return [];

  const chunks: string[] = [];
  let start = 0;

  while (start < normalized.length) {
    const end = Math.min(start + chunkSize, normalized.length);
    const slice = normalized.slice(start, end).trim();
    if (slice) chunks.push(slice);
    if (end >= normalized.length) break;
    start = Math.max(0, end - overlap);
  }

  return chunks;
}
```

```typescript
import fs from 'node:fs/promises';
import path from 'node:path';
import { WORKSPACE_DIR } from '../config/paths';
import { embedTexts } from './embedding';
import { splitTextIntoChunks } from './chunker';
import { insertDocumentWithChunks, type DocumentInfo } from './documents';
import { serializeEmbedding } from './vector';

const KNOWLEDGE_DIR = path.join(WORKSPACE_DIR, 'knowledge');
const MAX_FILE_SIZE = 10 * 1024 * 1024;
const ALLOWED_EXT = new Set(['.md', '.txt']);

export type ImportProgress =
  | { phase: 'reading' }
  | { phase: 'chunking'; chunkCount: number }
  | { phase: 'embedding'; done: number; total: number }
  | { phase: 'done'; document: DocumentInfo };

export async function importDocumentFromPath(
  sourcePath: string,
  onProgress?: (p: ImportProgress) => void,
): Promise<DocumentInfo> {
  onProgress?.({ phase: 'reading' });

  const resolved = path.resolve(sourcePath);
  const stat = await fs.stat(resolved);
  if (!stat.isFile()) throw new Error('不是有效文件');
  if (stat.size > MAX_FILE_SIZE) throw new Error('文件超过 10MB');

  const ext = path.extname(resolved).toLowerCase();
  if (!ALLOWED_EXT.has(ext)) throw new Error('M5 仅支持 .md / .txt');

  const text = await fs.readFile(resolved, 'utf8');
  const chunks = splitTextIntoChunks(text);
  if (!chunks.length) throw new Error('文件内容为空');

  onProgress?.({ phase: 'chunking', chunkCount: chunks.length });

  await fs.mkdir(KNOWLEDGE_DIR, { recursive: true });
  const filename = path.basename(resolved);
  const destPath = path.join(KNOWLEDGE_DIR, `${Date.now()}_${filename}`);
  await fs.copyFile(resolved, destPath);

  const relativePath = path.relative(WORKSPACE_DIR, destPath).replace(/\\/g, '/');
  const mimeType = ext === '.md' ? 'text/markdown' : 'text/plain';

  const BATCH = 16;
  const embeddedChunks: Array<{ content: string; embedding: Uint8Array }> = [];

  for (let i = 0; i < chunks.length; i += BATCH) {
    const batch = chunks.slice(i, i + BATCH);
    const vectors = await embedTexts(batch);
    for (let j = 0; j < batch.length; j++) {
      embeddedChunks.push({
        content: batch[j],
        embedding: serializeEmbedding(vectors[j]),
      });
    }
    onProgress?.({
      phase: 'embedding',
      done: Math.min(i + batch.length, chunks.length),
      total: chunks.length,
    });
  }

  const doc = insertDocumentWithChunks({
    filename,
    filepath: relativePath,
    mimeType,
    chunks: embeddedChunks,
  });

  onProgress?.({ phase: 'done', document: doc });
  return doc;
}
```

```typescript
import { embedText } from './embedding';
import { loadAllChunkEmbeddings } from './documents';
import { topKBySimilarity } from './vector';

export interface RetrievedChunk {
  documentId: string;
  filename: string;
  chunkIndex: number;
  content: string;
  score: number;
}

const MIN_SCORE = 0.35; // 过滤低相关 chunk，可调

export async function retrieveRelevantChunks(
  query: string,
  limit = 5,
): Promise<RetrievedChunk[]> {
  const trimmed = query.trim();
  if (!trimmed) return [];

  const stored = loadAllChunkEmbeddings();
  if (!stored.length) return [];

  const queryVec = new Float32Array(await embedText(trimmed));
  const hits = topKBySimilarity(
    queryVec,
    stored.map((s) => ({ data: s, embedding: s.embedding })),
    limit,
  );

  return hits
    .filter((h) => h.score >= MIN_SCORE)
    .map((h) => ({
      documentId: h.item.documentId,
      filename: h.item.filename,
      chunkIndex: h.item.chunkIndex,
      content: h.item.content,
      score: h.score,
    }));
}

export function formatRagForPrompt(chunks: RetrievedChunk[]): string | null {
  if (!chunks.length) return null;

  const body = chunks
    .map(
      (c, i) =>
        `<ref index="${i + 1}" source="${c.filename}" score="${c.score.toFixed(2)}">\n${c.content}\n</ref>`,
    )
    .join('\n\n');

  return `【参考文档】\n以下是从用户导入文档中检索到的相关片段，回答时请优先依据这些内容，并注明来源文件名：\n\n<reference>\n${body}\n</reference>`;
}
```

```typescript
import { cosineSimilarity, deserializeEmbedding } from '../rag/vector';

const SEMANTIC_DEDUPE_THRESHOLD = 0.88;

export function isSemanticallyDuplicateMemory(
  newEmbedding: Float32Array,
  existing: Array<{ content: string; embedding: Uint8Array | null }>,
): boolean {
  for (const item of existing) {
    if (!item.embedding) continue;
    const other = deserializeEmbedding(item.embedding);
    if (cosineSimilarity(newEmbedding, other) >= SEMANTIC_DEDUPE_THRESHOLD) {
      return true;
    }
  }
  return false;
}
```

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 百炼 embedding 模型名/维度与 chat 不同 | `.env` 可配 `EMBEDDING_MODEL`；维度从 API 响应动态读取 |
| chunk 量大时 embedding 费用 | 导入前显示 chunk 数；BATCH=16 减少请求次数 |
| 线性扫描变慢（>10k chunks） | M5 不优化；文档注释说明规模上限，未来可迁 better-sqlite3+sqlite-vec |
| `buildSystemPrompt` 变 async 影响调用链 | 仅 orchestrator 一处 await，编译器会报漏改 |
