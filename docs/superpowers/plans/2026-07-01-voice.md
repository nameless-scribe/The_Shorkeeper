# 语音能力实施计划（TTS + STT）

> **版本：** 0.2.0-draft  
> **日期：** 2026-07-01  
> **状态：** 待实施  
> **设计依据：** [DESIGN.md](../../DESIGN.md) §5.9 TTS、§6 AG-UI 事件  
> **关联里程碑：** 承接 M6-3（TTS 延后排期）

**Goal：** 为 The Shorekeeper 增加可用的语音输入与朗读能力：用户可通过麦克风说话填入聊天框；Agent 回复可点击朗读或自动播放；**通过百炼 CosyVoice 声音复刻使用自定义人声（非仅预设音色）**；保留 `tts_chunk` 事件管道用于后续流式播放。

**Architecture：** 遵循「主进程持有智能、渲染进程只展示」。TTS/STT API 调用与 API Key 均在 Main Process；渲染进程负责麦克风采集、Web Audio 播放、UI 控件。语音副作用通过现有 `broadcastAgentEvent` 广播，聊天窗统一订阅。

**Tech Stack：** 阿里云百炼 CosyVoice（TTS）+ Paraformer / Fun-ASR（STT，待 API 确认）· Web Audio API · MediaRecorder · 现有 AG-UI 事件流

## 系统架构

### 数据流（TTS）

```
run_finished（或用户点击 🔊）
  → tts-pipeline：stripMarkdownForSpeech(text)
  → 按句切分 → tts-engine.synthesize(sentence)
  → broadcast agent:event { tts_start }
  → broadcast { tts_chunk, audio: ArrayBuffer } × N
  → broadcast { tts_end }
```

### 数据流（声音复刻 · V1.5）

```
设置页「从音频创建音色」
  → 用户选择本地 wav/mp3/m4a（10–20s 推荐）
  → 主进程校验时长/格式 → 复制到 appearance/voice-samples/
  → 上传可访问 URL（见 § 样本托管策略）
  → POST voice-enrollment（action: create_voice）
  → 返回 voice_id（如 cosyvoice-v3.5-plus-shore-xxxxx）
  → 写入 app_settings voice.profiles + 设为当前 ttsVoiceId
  → 后续 synthesize 与预设音色相同：model=target_model, voice=voice_id
```

**关键约束（百炼官方）：**

- 复刻与合成必须使用**同一** `target_model`（默认 `cosyvoice-v3.5-plus`）
- 样本：10–20 秒推荐，≤60 秒；至少 5 秒连续清晰朗读；无 BGM / 环境噪 / 他人声；不要唱歌
- 复刻音色 ID 用法与预设 `longxiaochun` 等**完全相同**，播放器层无需区分

参考文档：[CosyVoice 声音复刻 API](https://help.aliyun.com/zh/model-studio/cosyvoice-clone-design-api)

### 数据流（STT）

```
用户按住 🎤（Renderer MediaRecorder）
  → 停止录音 → IPC voice:transcribe(ArrayBuffer)
  → Main stt-engine.transcribe(buffer)
  → 返回 { text, confidence? }
  → InputBar 填入文本（默认不自动 send）
```

### 配置模型

`app_settings` 键：

| 键 | 内容 |
|----|------|
| `voice.settings` | 当前朗读/STT 行为配置 |
| `voice.profiles` | 用户创建的复刻音色列表（JSON 数组） |

```typescript
/** 合成模型，须与复刻时的 target_model 一致 */
type CosyVoiceModel =
  | 'cosyvoice-v3.5-plus'
  | 'cosyvoice-v3.5-flash'
  | 'cosyvoice-v3-plus'
  | 'cosyvoice-v3-flash';

interface VoiceSettings {
  ttsEnabled: boolean;
  ttsAutoPlay: boolean;
  /** 当前合成模型（复刻音色必须与此一致） */
  ttsModel: CosyVoiceModel;
  /** 当前 voice 参数：预设 ID 或复刻 voice_id */
  ttsVoiceId: string;
  /** preset=官方音色库；cloned=用户复刻 */
  ttsVoiceSource: 'preset' | 'cloned';
  /** 当 ttsVoiceSource=cloned 时，指向 voice.profiles 中的 id（便于 UI 展示） */
  activeClonedProfileId: string | null;
  ttsRate: number;
  ttsMaxChars: number;
  sttEnabled: boolean;
  sttLanguage: 'zh' | 'en' | 'auto';
  pushToTalk: boolean;
  sttAutoSend: boolean;
  playbackTarget: 'chat' | 'pet' | 'both';
}

/** 本地持久化的复刻条目 */
interface ClonedVoiceProfile {
  id: string;                    // UUID，应用内主键
  name: string;                  // 显示名，如「守岸人·复刻」
  voiceId: string;               // 百炼返回的 voice_id
  targetModel: CosyVoiceModel;   // 创建时指定的 target_model
  sampleFilename: string;        // appearance/voice-samples/ 下文件名
  sampleDurationSec: number;
  languageHints: ('zh' | 'en')[];
  createdAt: number;
  lastUsedAt?: number;
}

const VOICE_DEFAULTS: VoiceSettings = {
  ttsEnabled: true,
  ttsAutoPlay: false,
  ttsModel: 'cosyvoice-v3.5-plus',
  ttsVoiceId: 'longxiaochun',       // 未复刻前的 fallback 预设
  ttsVoiceSource: 'preset',
  activeClonedProfileId: null,
  ttsRate: 1.0,
  ttsMaxChars: 2000,
  sttEnabled: true,
  sttLanguage: 'zh',
  pushToTalk: true,
  sttAutoSend: false,
  playbackTarget: 'chat',
};
```

**本地样本目录：** `D:\SQLlite\appearance\voice-samples\`（与壁纸/头像同根；DB 只存文件名，见 `src/config/paths.ts` 扩展）。

**API Key：** 复用设置 → API 设置中的百炼 DashScope Key（`DASHSCOPE_API_KEY` / 现有 `OPENAI_API_KEY` 若同为百炼则共用）。语音合成与复刻 endpoint 可能与 Chat 不同，见下方 `.env` 覆盖。

### 样本托管策略（复刻 API 需要公网 URL）

百炼 `create_voice` 的 `url` 参数要求**可公网访问的音频 URL**。桌面应用可选方案（按优先级）：

| 方案 | 说明 | 推荐 |
|------|------|------|
| **A. 用户自备 OSS** | 设置页填 OSS 临时上传凭证或预签名 URL 模板；主进程 PUT 后调复刻 | 自用最稳 |
| **B. 百炼/OSS 一键上传** | 若 DashScope SDK 支持直传文件则优先用 SDK | 待 Step 0 确认 |
| **C. 手动 URL** | 用户先把样本传到网盘/OSS，粘贴 URL 到设置页 | V1.5 兜底，实现最快 |

V1.5 **至少交付 C**；A 作为增强项写入 Task V1.5-2。

`.env` 可选覆盖：

```env
VOICE_API_KEY=              # 默认同 Chat Key
VOICE_TTS_ENDPOINT=         # CosyVoice 合成 endpoint
VOICE_ENROLLMENT_ENDPOINT=  # voice-enrollment  endpoint
VOICE_DEFAULT_MODEL=cosyvoice-v3.5-plus
```

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 百炼语音 API 与 Chat 不同 endpoint | 集成成本 | `VoicePage` 可选独立 Base URL；文档写清 MODELS.md 补充节 |
| IPC 传输大 ArrayBuffer | 卡顿 | 单 chunk ≤ 512KB；或写 temp 文件 + `sk-asset://` 播放（V2 优化项） |
| TTS 与流式 text 竞态 | 读未完成回复 | **仅** `run_finished` 后合成；不跟 `text_delta` |
| 多窗口重复播放 | 双重声音 | `playbackTarget` 配置；默认 chat |
| 麦克风权限 | STT 不可用 | 明确 UI 提示；Windows 通常无需额外处理 |
| 计费 | 用户成本 | 默认 `ttsAutoPlay: false`；设置页注明合成按量计费；复刻创建通常免费 |
| 复刻需公网 URL | 无法从纯本地文件直接复刻 | V1.5 支持粘贴 URL；可选 OSS 自动上传 |
| model / voice 不匹配 | 合成失败 | 激活复刻时校验 `targetModel === ttsModel`；UI 联动锁定 |
| 复刻音色 1 年未用被删 | 朗读突然失败 | 启动时可选 `listEnrolledVoices` 对账；失效项标记「需重新创建」 |
| 样本版权 | 法律风险 | 设置页免责声明：样本需用户自有授权，自用自负 |
| 复刻非 1:1 原声 | 预期落差 | UI 说明为「声线相似 TTS」，非原配音还原 |
