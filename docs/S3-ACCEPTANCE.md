# S3 工具、技能与权限验收集

版本：0.1.0  
日期：2026-09-11

## 1. 当前范围

S3.1 已完成，固定入口为：

```powershell
pnpm test:s3
pnpm typecheck
```

S3.1 只收口工具结果契约和错误分类，不提前改变权限策略、技能触发逻辑或高风险操作确认规则。

## 2. S3.1 通过标准

- 工具结果包含稳定的成功/失败语义。
- 失败结果包含 `errorCategory`，不依赖界面重新猜测错误类型。
- `metadata` 和 `artifacts` 可以随结果传递且不丢失。
- malformed result 会降级为 `internal_error`，不会被误报为成功。
- Agent 工具事件和运行诊断记录同一工具错误类别。
- 定时提醒快捷路径也经过同一结果归一化入口。

## 3. 后续验收范围

- S3.2：权限策略集中化、工作区路径和高风险确认。
- S3.3：技能生命周期、触发条件、白名单和重复注入防护。
- S3.4：副作用工具幂等、产物校验和失败恢复。
- S3.5：文件、文档、表格、RAG、定时任务和 MCP 集成场景。
- S3.6：总验收和私人小模型兼容性复测。
