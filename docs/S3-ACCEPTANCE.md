# S3 工具、技能与权限验收集

版本：0.1.1
日期：2026-09-11

## 1. 当前范围

S3.1-S3.6 已完成，固定入口为：

```powershell
pnpm test:s3
pnpm typecheck
```

S3.2 已集中收口文件路径、写入确认、后台自动化确认和 shell 默认拒绝策略；S3.3 已收口技能生命周期和重复注入防护；S3.4 已补齐快捷路径的权限复用、幂等和文件失败恢复；S3.5-S3.6 已完成集成验收和总体验收。

## 2. S3.1 通过标准

- 工具结果包含稳定的成功/失败语义。
- 失败结果包含 `errorCategory`，不依赖界面重新猜测错误类型。
- `metadata` 和 `artifacts` 可以随结果传递且不丢失。
- malformed result 会降级为 `internal_error`，不会被误报为成功。
- Agent 工具事件和运行诊断记录同一工具错误类别。
- 定时提醒快捷路径也经过同一结果归一化入口。

## 3. S3.2 通过标准

- 文件读写和文档转换的所有输入/输出路径都限制在工作区根目录内。
- 绝对路径、路径穿越和指向工作区外的 symlink 均被拒绝。
- `readonly` 禁止写入，`confirm` 模式写入前需要用户确认，`full` 模式仍保留工作区边界。
- 创建/删除后台定时任务需要用户确认。
- shell 权限默认拒绝；网络和 MCP 仍由现有配置策略控制。

## 4. S3.3 通过标准

- 手动技能和命中关键词的自动技能才会进入本轮上下文。
- 技能按优先级稳定排序，重复 id 只注入一次。
- 启用技能列表只接受非空字符串并自动去重；不存在的技能不能被写入启用列表。
- 技能工具白名单仍按并集计算，并由现有 Agent Registry 测试覆盖。

## 5. S3.4 通过标准

- Agent 主循环和定时提醒快捷路径都经过同一权限解析入口。
- 快捷路径不会绕过后台自动化确认。
- 定时任务快捷创建支持幂等键，重复重试不会创建重复任务。
- 工具失败、取消和权限拒绝仍通过统一结果归一化返回。
- 权限失败时不会执行对应副作用工具。

## 6. S3.5 通过标准

- 文件读写、文档生成/转换、Excel 读写、RAG 检索、定时任务和 MCP 工具契约均有固定回归入口。
- 工具注册表生成的模型 schema 名称唯一，核心工具权限声明稳定。
- 文件产物可以读回，失败生成不会留下临时文件或破坏旧文件。

## 7. S3.6 总验收

- S3 收口时固定验收：`pnpm test:s3`，22 个测试文件、102 项全部通过（历史快照）。
- 当前全量回归已扩展到 147 个测试文件、691 项通过（2026-09-13，P1 收口后）；后续以 `pnpm test` 实时结果为准，TypeScript 检查和生产构建继续作为交付门槛。
- 模型兼容性以 OpenAI-compatible 流式、工具调用、错误恢复和上下文预算测试作为本地契约验收。
- 真实第三方 MCP Server 和私人模型 endpoint 属于部署环境验收，不作为本地 S3 阶段阻断项。
