# S2 Agent 运行时验收集

版本：0.1.0  
日期：2026-09-11

## 1. 用途

本验收集固定 S2 的运行时稳定性基线，也作为后续私人云端小模型接入时的兼容性入口。模型或 Agent 运行时代码变更后，至少执行：

```powershell
pnpm test:s2
pnpm typecheck
pnpm test
pnpm build
pnpm test:electron
```

涉及数据库、Electron 或安装包依赖时，额外执行：

```powershell
pnpm db:health
pnpm test:packaged-native
```

## 2. 自动化场景

- 普通对话：模型文本流产生唯一完成终态，非持久化通话仍包含当前用户消息。
- 连续工具调用：多轮工具结果可以回注模型，达到轮次上限时可控结束。
- 工具失败：失败结果和错误类别可诊断，不会被误报为成功。
- 模型超时：请求收到取消信号，run 进入错误终态并释放资源。
- 用户取消：停止后续模型和工具工作，不持久化半截 assistant 回复。
- 长会话：system prompt 与历史消息受 Token 预算约束，压缩原因可观测。
- RAG 模式：`catalog`、`auto`、`tool` 使用固定且可测试的注入策略。
- 定时任务：复用 orchestrator 和会话锁，成功或失败后均释放会话。
- 语音中断：中断只取消所属 run，不提前释放或误删后续 run 的锁。
- 应用退出：停止接收新 run，取消前台和后台任务，等待底层工作收敛后关闭数据库。

## 3. 私人模型实机验收

切换模型配置后，用同一会话依次执行以下场景，并通过运行编号检查诊断：

1. 发送普通中文问题，确认流式回复完整且只有一个终态。
2. 请求执行一个只读工具，再根据结果连续执行第二个工具。
3. 让一个工具返回错误，确认回复明确说明失败和可恢复动作。
4. 在生成中点击停止，确认下一条消息可以正常发送。
5. 使用超过模型窗口的历史或测试文本，确认上下文发生可解释裁剪而非请求崩溃。
6. 触发一次 Agent 定时任务，确认不会与正在进行的普通聊天抢占同一会话。
7. 开始语音通话，在思考阶段中断，再发送下一句，确认状态回到监听且无旧回复串入。
8. 在运行或后台压缩期间退出并重新启动，确认数据库健康、历史可读且会话可继续。

## 4. 通过标准

- `test:s2`、类型检查、完整测试、构建和 Electron smoke 全部通过。
- 每个 run 恰好有一个 `finished`、`cancelled` 或 `error` 终态。
- 取消、超时、工具失败和后台失败不会留下会话锁或半截 assistant 消息。
- 最近 100 条脱敏诊断能按 `runId` 查询，不包含消息正文、工具参数或密钥。
- 上下文超预算时优先保留稳定人设、活动技能、工具规则、摘要、RAG 引用和最新消息。
- 应用重启后数据库完整性正常，不存在运行状态残留。

实机模型的回答质量、工具参数正确率和中文人设遵循属于模型兼容结果，不由单元测试代替。
