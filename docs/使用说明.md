# The Shorekeeper 使用说明

面向日常使用者的功能说明。开发启动与打包见 [README.md](../README.md)；架构见 [DESIGN.md](DESIGN.md)。

## 首次配置

1. **设置 → API 设置** — 填写模型 API Key 与接入地址（见 [MODELS.md](MODELS.md)）
2. **设置 → 人设** — 编辑核心 System Prompt
3. **设置 → 插件** — 按需开启联网搜索、多格式编写（Excel / Word / PDF 等）
4. **设置 → 技能** — 启用需要的技能包（见下文）
5. **设置 → 语音** — 可选：TTS 朗读、语音通话（需百炼 Key / 复刻 voice_id）
6. **设置 → 泰提斯终端** — 导入知识库文档（可选）

工作区默认在 `D:\SQLlite\workspace`（可通过 `.env` 的 `SHOREKEEPER_WORKSPACE_DIR` 修改；无 `D:` 盘时打包版会回退到应用数据目录）。Agent 读写文件、生成报表均在此目录内。

**请勿**把真实 API Key 写进仓库文档或提交 `.env`。

## 技能系统

技能来自安装包或项目根目录下的 `skills/*/SKILL.md`。在 **设置 → 技能** 中开关后生效。

### 常驻 vs 按需

| 类型 | 行为 |
|------|------|
| **常驻** | 启用后**每轮对话**都会注入技能说明；只适合确实需要全局生效的规则 |
| **按需** | 仅当本条消息命中明确触发词时注入；普通闲聊不会占用额外上下文 |

上传 Excel 附件后，消息会包含文件路径和 `.xlsx` 标记，因此会激活 Excel 能力。只有用户明确提到待办、任务表或项目进度时才激活进度技能，普通报表不会自动导入待办。

### 内置技能一览

| 技能 | 类型 | 适用场景 | 依赖 |
|------|------|----------|------|
| Excel 表格处理 | 自动 | 分析/汇总/生成 `.xlsx` | 插件「多格式编写」 |
| 多步任务执行 | 按需 | 多文件、批量或三次以上工具操作的复杂任务 | 多格式编写 + 文件工具 |
| 进度与待办 | 自动 | 从 Excel 导入待办、查进度、更新状态 | 多格式编写 |
| 工作区文档维护 | 按需 | 安全修改 `.md` / `.txt`，局部编辑优先精确替换 | 文件工具 |
| 文档转 Markdown | 自动 | Word / 文本转 `.md` | 多格式编写 |

### 使用建议

- **表格分析**：上传或提及 `.xlsx` 即可触发 Excel；修改现有工作簿时使用保留结构的单元格更新工具。
- **进度管理**：明确说「导入待办」「任务表」「项目进度」才会触发，不会把普通 Excel 当作任务表。
- **改 Markdown**：明确说「修改文档」「写回文件」等；路径已由附件给出时不会重复列目录。
- **复杂多文件任务**：说「执行计划」「批量处理」等；简单任务不会强制创建计划。
- **多个带白名单的技能同时开启**：可用工具为各技能白名单的**并集**（不是交集）。记忆、定时、知识库检索等核心能力始终可用。

### 自定义技能

参考现有产品 Skill 新建目录并编辑 frontmatter：

```yaml
---
name: my-skill
description: 简短说明
metadata:
  shorekeeper:
    displayName: 我的技能
    version: 1.0.0
    trigger: auto
    kind: capability
    matchKeywords: [关键词1, 关键词2]
    priority: 10
    allowedTools: [read_file, list_dir]
    requiredTools: [read_file]
    conflictsWith: [another-skill]
---
```

正文为注入模型的指令片段。顶层遵循标准 Agent Skill frontmatter；Shorekeeper 专属配置放在 `metadata.shorekeeper`。开发时放在项目根 `skills/`；打包后会一并打入安装包。加载器会校验必填字段、自动触发词、name/目录一致性和重复 id；无效 Skill 会显示诊断且不能启用。

## 插件与工具

**设置 → 插件** 控制工具是否注册到 Agent：

| 插件 | 相关工具 |
|------|----------|
| 多格式编写 | `read_xlsx`, `update_xlsx_cells`, `gen_xlsx`, `convert_to_markdown`, `gen_docx`, `gen_pdf` 等 |
| 联网搜索 | `web_search`, `fetch_url` |
| 记账 / 生活 | `bookkeeping`, `travel_plan` 等 |

插件关闭导致必需工具缺失时，对应 Skill 本轮不会激活，并会向 Agent 提供明确的缺失工具提示。

技能页底部的“最近运行诊断”显示本次应用启动后的最近运行，包括激活的 Skill、触发原因、冲突或缺失工具、工具调用次数和错误类别。诊断不保存用户消息正文，重启应用后清空。

## 工作区与附件

- 聊天中上传的文件会导入工作区；`.xlsx` 会在发送前**预解析**为文本块 appended 到消息，便于模型直接分析。
- `.pdf` 与 `.docx` 上传后由 `convert_to_markdown` 转成 `.md` 再读。PDF 会按版面重建表格（含格内换行与合并标题行），照片抽到与 `.md` 同名的 `.assets/` 目录并在正文引用，每页有 `<!-- page N -->` 标记；扫描件没有文字层时会保留各页图片（最长边至多 3600 像素，图纸标注可读）并在开头写明"未支持 OCR，未能识别文字"，不会静默返回空内容。
- `gen_pdf` 的正文按 Markdown 排版（标题、列表、表格、粗斜体、`---` 分页），中文用系统字体，超长自动分页。
- 读取文件前 Agent 应 `list_dir` 确认路径；不要猜测《》书名号或口述标题对应的文件名。
- 修改文件须调用 `write_file` 等工具真正写入；仅在回复里描述「已修改」不算完成。

## 知识库（泰提斯终端）

- 支持导入 MD、TXT、PDF、DOCX 等；RAG 检索模式见 **设置 → 性能**（`catalog` / `auto` / `tool`）。
- 对话中说「写入知识库」可归档当前会话到知识库。
- 检索优化（邻居扩展、FTS 优先、文档路由等）见 [RAG-OPTIMIZATION.md](RAG-OPTIMIZATION.md)；高级开关可在 `.env` 配置（如 `RAG_FTS_FIRST`、`RAG_NEIGHBOR_WINDOW`）。

## 语音

- **朗读：** 设置 → 语音，配置 CosyVoice（默认可复用对话用百炼 Key）；聊天消息可按需或自动朗读。
- **通话：** 独立通话窗（`?panel=call`）；STT → Agent → 复刻音色 TTS。需可用的复刻 `voice_id`，并保证构建时已同步 `public/vad/`（`pnpm dev` / `pnpm dist` 会自动执行）。
- TTS 与通话均已落地；架构说明见 [DESIGN.md](DESIGN.md) §5.9。

## 助理提问

- 助理在动手前判断信息够不够；歧义会改变结果时（改哪份文件、按哪个日期、发给谁）会弹出一个问题窗口，给出选项和"其他"输入框，回答后才继续。
- 窗口里按 Esc 或点"稍后再答"，这一步就停下，助理会告诉你它在等什么；回答窗口 10 分钟无人处理会超时，同样停下。
- 高风险操作（写文件、删除）仍然走权限确认弹窗，提问不能代替确认。语音通话中不弹窗，助理直接用语音问。

---

## 定时提醒

- 在聊天中说明时间即可（如「每天 17:30 提醒我」）；须由 Agent 调用 `create_scheduled_task` 才会真正创建。
- 提醒为**应用内弹窗**，需 Shorekeeper 保持运行，不是系统闹钟。

---

## 用户待办

启用「进度与待办」技能后，可：

1. 上传进度 Excel → `import_tasks_from_xlsx` 导入
2. `list_user_tasks` 查询（可按状态筛选）
3. `update_user_task` 更新状态（默认尝试回写 Excel）

设置页 **用户待办** 可查看与管理已导入任务。

## 常见问题

**读取 Excel 报错 `Workbook is not a constructor`**  
已在 v1.2+ 修复；请重新 `pnpm dev` 或安装最新构建。

**说了「表格」但 Agent 不用 Excel 工具**  
检查：① 技能是否已在设置中启用；② 插件「多格式编写」是否开启；③ 文件是否在工作区内且路径正确。

**自动技能未触发**  
查看设置页该技能的「触发词」；消息中须包含其中之一（不区分大小写）。
