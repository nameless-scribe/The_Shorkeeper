# 企业 OA 管理系统 · 功能清单与需求说明（V2）

> **文档性质：** 产品功能清单 / 业务需求参考  
> **系统名称：** 企业 OA 管理系统（通用版）  
> **版本：** V2  
> **适用场景：** 行政、人事、审批、财务报销、流程流转、系统运维  
> **终端支持：** PC 端后台 + 移动端小程序 / APP  
> **定制说明：** 支持客户定制

---

## 1. 系统概述

本企业 OA 管理系统围绕**行政、人事、审批、财务报销、流程流转、系统运维**等核心场景搭建，集成以下七大模块：

| 序号 | 模块 | 核心能力 |
|------|------|----------|
| 1 | 通知公告 | 企业信息发布、阅读回执、推送与归档 |
| 2 | 系统管理 | 用户、组织、角色权限、菜单、字典、日志 |
| 3 | 工作流程 | BPMN 流程建模、表单、实例与任务管理 |
| 4 | 审批中心 | 发起申请、待办/已办、抄送、快捷审批 |
| 5 | 人事管理 | 员工档案、合同、岗位、入转调离 |
| 6 | 假勤管理 | 班次、考勤组、打卡、排班、统计报表 |
| 7 | 报销管理 | 费用报销、差旅报销、审批与台账 |

**设计目标：** 实现企业线上无纸化办公，统一流程入口、数据互通、权责清晰，适配中小型及集团型企业内部协同办公需求。

---

## 2. 通知公告模块

企业公告与通知的信息发布与管理，支持推送至**全员**或**指定范围**（指定部门 / 指定人员）。

### 2.1 业务能力

- **公告发布：** 管理员或部门负责人新建公告，填写标题、内容、附件、生效时间、可见范围
- **公告分类：** 行政通知、人事通知、制度文件、紧急通知、公司新闻
- **阅读回执：** 查看已读 / 未读人员，支持一键催阅
- **公告管理：** 编辑、撤回、置顶、下线、归档、删除
- **前端展示：** 首页弹窗提醒、未读红点标记、历史公告检索筛选

### 2.2 功能清单

| 功能 | 说明 |
|------|------|
| 公告列表 | 展示公告编号、标题、类型（通知/公告）、状态、创建时间 |
| 新增公告 | 创建新的通知或公告 |
| 编辑公告 | 修改公告内容 |
| 删除公告 | 删除单条公告记录 |
| 批量删除 | 批量删除选中公告 |
| 公告推送 | 将公告推送给目标用户或部门 |
| 搜索筛选 | 按公告标题、状态筛选 |
| 状态管理 | 开启 / 关闭公告 |

## 3. 系统管理模块

提供租户、用户、角色、组织、菜单、字典、消息与审计等基础能力，支撑全系统权限与配置管理。

### 3.1 模块概览

| 子模块 | 说明 |
|--------|------|
| 租户管理（2.1） | 多租户架构下的租户信息管理，支持多企业 / 多组织独立使用 |
| 用户管理（2.2） | 系统用户账号增删改查，账号状态控制与密码管理 |
| 角色管理（2.3） | 内置角色与自定义角色，菜单权限与数据权限分离 |
| 菜单管理（2.4） | 系统菜单树形配置，多级菜单、权限标识、组件路径 |
| 部门管理（2.5） | 企业组织架构，支持多级部门树 |
| 字典管理（2.6） | 各业务模块下拉选项等基础数据 |
| 消息中心（2.7） | 站内信、通知推送 |
| 审计日志（2.8） | 操作日志记录与查询，支持审计追溯 |

### 3.2 通用管理能力

- **用户管理：** 员工账号新增、启用 / 禁用、重置密码、信息修改
- **组织架构：** 部门新增、调整、合并、删除，树形架构展示
- **角色权限：** 自定义角色（管理员、部门主管、普通员工、财务、人事），配置菜单权限、操作权限、数据查看权限
- **菜单配置：** 自定义系统侧边菜单栏，隐藏 / 显示功能入口
- **日志管理：** 登录日志、操作日志、流程修改日志，可追溯审计
- **参数配置：** 系统名称、水印、文件大小限制、审批超时规则、短信 / 消息推送配置

### 3.3 角色管理功能清单

| 功能 | 说明 |
|------|------|
| 角色列表 | 展示角色编号、名称、类型、标识、显示顺序、状态、创建时间 |
| 新增角色 | 创建新角色 |
| 编辑角色 | 修改角色信息 |
| 删除角色 | 删除角色 |
| 菜单权限 | 配置角色的菜单访问权限 |
| 数据权限 | 配置角色的数据访问范围 |
| 搜索筛选 | 按角色名称、标识、状态、创建时间筛选 |

## 4. 工作流程模块

支持 BPMN 流程模型管理、可视化流程设计、流程实例与任务运行监控。

### 4.1 业务能力

- **流程模板配置：** 自定义流程表单、审批节点、流转规则
- **常用模板：** 请假、加班、出差、费用报销、用章申请、采购申请、合同审批等
- **流程设计器：** 可视化拖拽配置节点（发起人 → 直属领导 → 部门经理 → 总经理 → 财务），支持会签、或签、抄送、转办、驳回重提
- **流程分类：** 人事类、行政类、财务类、业务类
- **流程监控：** 管理员查看所有进行中、已完成、已驳回、已撤销流程
- **流程归档：** 历史流程统一归档，支持按时间、类型、申请人检索导出

### 4.2 子模块说明

| 子模块 | 说明 |
|--------|------|
| 流程模型（3.1） | BPMN 流程模型管理，支持 SIMPLE 设计器，按分类组织流程 |
| 流程表单（3.2） | 流程关联的表单设计与配置 |
| 流程分类（3.3） | 按业务类型组织流程（人事 / 财务 / 假勤等） |
| 用户分组（3.4） | 用于流程审批节点的人员分配 |
| 流程监听器（3.5） | 流程事件监听器，支持执行中自定义逻辑 |
| 流程表达式（3.6） | 流程条件表达式，用于分支判断 |
| 流程实例（3.7） | 已发起流程实例管理，查看运行状态 |
| 流程任务（3.8） | 流程任务管理，查看和分配任务 |

### 4.3 流程模型功能清单

| 功能 | 说明 |
|------|------|
| 模型列表 | 按分类展示流程模型（人事 / 财务 / 假勤等） |
| 新建模型 | 创建新的流程模型 |
| 修改模型 | 编辑流程设计 |
| 复制模型 | 复制现有流程模型 |
| 发布模型 | 发布流程模型使其生效 |
| 版本管理 | 流程模型版本控制（v1 / v2 / v3） |
| 搜索流程 | 按流程名称搜索 |

## 5. 审批中心模块

统一的流程审批工作台，覆盖**发起申请、待办处理、进度跟踪**等完整审批链路。

### 5.1 业务能力

| 能力 | 说明 |
|------|------|
| 我的待办 | 所有待我审批、待我处理单据，消息实时提醒 |
| 我的已办 | 已审批通过、驳回、退回单据记录 |
| 我的发起 | 本人提交的所有申请单，查看流转进度与审批意见 |
| 抄送我的 | 仅查看、无需审批的抄送单据 |
| 审批操作 | 同意、驳回（填写原因）、转办他人、加签、撤回申请 |
| 快捷审批 | 移动端一键审批，批量处理多条待办 |

### 5.2 子模块

| 子模块 | 说明 |
|--------|------|
| 发起申请（4.1） | 发起请假、报销、转正等各类审批申请 |
| 我的申请（4.2） | 查看本人发起的所有审批申请及当前状态 |
| 待办任务（4.3） | 查看需本人处理的审批任务 |
| 已办任务（4.4） | 查看本人已处理完成的审批任务记录 |
| 抄送我的（4.5） | 查看抄送给本人的流程通知 |

### 5.3 待办任务功能清单

| 功能 | 说明 |
|------|------|
| 任务列表 | 展示流程名称、摘要、发起人、发起时间、当前任务、任务时间等 |
| 任务筛选 | 按任务名称、流程分类筛选 |
| 高级筛选 | 多条件组合筛选 |
| 任务办理 | 进入任务处理页面进行审批操作 |
| 分页浏览 | 支持分页，默认 10 条 / 页 |

## 6. 人事管理模块

覆盖员工全生命周期档案管理与入转调离流程。

### 6.1 业务能力

- **员工档案：** 入职信息、合同信息、学历履历、奖惩记录、岗位调整、离职信息
- **入转调离流程：** 入职 / 转正 / 调岗 / 离职线上发起审批，人事台账自动更新
- **奖惩管理：** 嘉奖、处罚录入登记，关联员工档案
- **人员统计：** 部门人数、在职 / 离职 / 试用期人员统计报表导出

### 6.2 子模块

| 子模块 | 说明 |
|--------|------|
| 员工档案（5.1） | 企业员工档案管理，部门树形导航与多维度筛选 |
| 员工合同（5.2） | 劳动合同管理，签订日期、到期提醒 |
| 岗位管理（5.3） | 岗位名称、职责、层级等 |
| 转正申请（5.4） | 转正审批流程，试用期到期自动提醒 |

### 6.3 员工档案功能清单

| 功能 | 说明 |

| 员工列表 | 展示工号、姓名、部门、岗位、登录账号、账号状态、员工状态、类型、手机号、邮箱 |
| 新增员工 | 创建新的员工档案 |
| 导入员工 | 批量导入员工数据 |
| 导出员工 | 导出员工档案数据 |
| 搜索筛选 | 按部门、登录账号、工号、手机号、姓名、状态、类型、身份类型、入职日期等筛选 |
| 详情查看 | 查看员工详细信息 |

## 7. 假勤管理模块

考勤规则配置、员工打卡排班、异常标记与统计报表。

### 7.1 业务能力

- **考勤基础设置：** 上下班时间、班次设置、节假日配置、迟到早退规则
- **请假管理：** 事假、病假、年假、婚假、产假等类型申请，关联审批流程
- **加班管理：** 加班申请、加班时长核算、加班抵扣调休登记
- **出差外勤：** 出差报备、外勤打卡定位、出差时长统计
- **考勤核算：** 自动汇总月度考勤，导出考勤报表，异常考勤（缺卡、旷工）标记提醒

### 7.2 子模块

| 子模块 | 说明 |
|--------|------|
| 班次管理（6.1） | 工作时间班次定义，自定义考勤时间与关联考勤组 |
| 考勤组管理（6.2） | 员工分组并关联班次和考勤规则 |
| 考勤地点管理（6.3） | 打卡地点与打卡范围设置 |
| 我的考勤（6.4） | 员工查看个人打卡记录、迟到 / 早退状态 |
| 我的排班（6.5） | 员工查看个人排班安排 |
| 每日统计（6.6） | 按日出勤、迟到、早退、缺卡等统计 |
| 汇总统计（6.7） | 按月 / 周汇总考勤数据，生成报表 |

### 7.3 班次管理功能清单

| 功能 | 说明 |
|------|------|
| 班次列表 | 展示班次名称、考勤时间、使用中的签到组 |
| 新建班次 | 创建新的工作班次 |
| 编辑班次 | 修改班次信息 |
| 删除班次 | 删除班次 |
| 搜索班次 | 按班次名称搜索 |

## 8. 报销管理模块

费用与差旅报销申请、审批流转、台账与财务统计。

### 8.1 通用规则

- **费用类型：** 差旅费、办公费、招待费、交通费、材料费等
- **报销单填写：** 事由、金额、票据上传、费用明细分摊
- **报销审批流：** 员工提交 → 部门审核 → 财务核验 → 领导终审 → 打款登记
- **报销台账：** 所有报销单据明细、付款状态、已付 / 待付统计
- **月度财务报表：** 部门费用汇总、个人报销统计、费用占比分析，支持 Excel 导出

### 8.2 费用报销（7.1）

| 功能 | 说明 |
|------|------|
| 报销列表 | 展示申请编号、报销单号、报销人、部门、状态、总金额、说明、申请时间 |
| 发起报销 | 创建新的费用报销申请 |
| 报销明细 | 添加费用明细（费用类型、日期、金额、说明、附件） |
| 附件上传 | 上传报销凭证（doc / docx / pdf / jpg / jpeg / png / xls / xlsx，单文件 ≤ 20MB） |
| 审批流程 | 显示审批流程（发起人 → 审批人 → 抄送人 → 结束） |
| 详情查看 | 查看报销详情 |
| 进度跟踪 | 查看审批进度 |
| 取消报销 | 取消未完成的报销申请 |
| 重新发起 | 被驳回后重新发起报销 |
| 搜索筛选 | 按报销单号、申请时间、费用发生日期、审批结果、报销说明筛选 |

### 8.3 差旅报销（7.2）

| 功能 | 说明 |
|------|------|
| 报销列表 | 展示申请编号、报销单号、报销人、部门、状态、出差地点、天数、总金额、事由、申请时间 |
| 发起报销 | 创建新的差旅报销申请 |
| 搜索筛选 | 按报销单号、出差地点、申请时间、费用发生日期、审批结果、出差事由筛选 |
| 详情 / 进度 / 取消 | 同费用报销 |

## 9. 模块关系摘要

- 人事、假勤、报销等业务单据通过**工作流程**定义审批链路，在**审批中心**统一办理
- **系统管理**中的角色与数据权限控制各模块可见范围与操作能力
- **通知公告**可向审批相关人员推送待办提醒与制度变更
