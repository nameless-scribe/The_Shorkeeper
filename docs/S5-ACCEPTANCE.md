# S5 守岸人私人助理化验收集

版本：0.1.0  
日期：2026-09-11

## 1. 用途

本验收集固定 S5 的私人助理契约：模式只改变工作倾向，不绕过 S3 权限、确认和错误分类。模型、人设或助理模式变更后，至少执行：

```powershell
pnpm test:s5
pnpm typecheck
pnpm test
```

## 2. 自动化场景

固定场景见 `src/assistant/scenarios.ts`：

- 普通闲聊（`companion`）：不自动提取记忆，默认不产生副作用。
- 推进多步任务（`focus`）：可推进任务，写入仍走确认。
- 整理工作区（`organize`）：先检索再整理；覆盖/删除前确认。
- 知识库问答（`organize`）：只读检索，失败时不编造来源。
- 审核计划（`review`）：默认只读，不直接改文件或计划。
- 创建提醒（`focus`）：必须经过现有定时任务确认链路。

`organize` 与 `companion` 各覆盖成功、工具失败、用户取消、权限不足、需要确认五条路径。

## 3. 记忆与主动性

- 自动提取只静默保存高置信、非敏感的稳定偏好；关系类、低置信和敏感内容进入待确认队列。
- 设置 → 记忆 可列出、编辑、删除已保存长期记忆。删除带 key 的记忆后，自动提取不会静默恢复同一条；用户仍可明确要求记住。
- `companion` 不调度自动记忆提取，也不把该轮标记为已提取，切回其他模式后仍可提取。
- 已明确创建的提醒默认通知；关闭开关、重复窗口和周期任务的安静时段会抑制弹窗。
- 一次性提醒在安静时段会被推迟到时段结束，不会被静默消费。
- 提醒可见性决策可按任务查询最近记录，且不会把会话打成失败。

## 4. 建议的使用走查

用同一应用依次执行以下三条，确认界面提示与工具行为一致。这是使用走查，不是框架稳定化的阻断项：

1. 将会话切到「轻陪伴」，闲聊两轮后打开设置中的待确认记忆：不应因闲聊自动新增记忆。
2. 切到「整理归档」，先请她列出工作区或知识库资料，再请她写入/覆盖文件：写入前必须确认，取消后原文件仍在。
3. 切到「审核检查」，请她审核一份计划并尝试修改：默认只读说明风险；明确要求修改后才进入原有确认框。

可选补充：创建一个一次性提醒，将安静时段覆盖当前时间，确认到期时不弹窗，安静时段结束后才会出现。

## 5. 通过标准

- `pnpm test:s5`、类型检查和完整测试通过。
- 四种模式的提示都声明不改变工具权限。
- 工具失败、取消和权限拒绝不会被标记为成功。
- 主动提醒可关闭、可去重、可推迟，且不改变会话成功/失败状态。
- 人设正文仍由用户编辑；模式只追加短小、可审计的行为约束。

桌面端三条场景走查用于确认真实使用手感，不替代上述自动化基线。
