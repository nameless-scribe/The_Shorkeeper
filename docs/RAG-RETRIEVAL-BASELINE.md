# RAG 检索质量基线

S4 固定基线包含 4 份小型规则文档和 12 个问答样例，覆盖账户、发布、报销和数据保留主题。每个样例记录期望来源、关键事实和实际召回来源；`auto` / `tool` 还记录事实覆盖率与来源引用率，`catalog` 记录目录是否包含期望来源。

运行：

```text
pnpm rag:baseline
```

当前基线使用确定性的稀疏检索作为离线回归，避免 CI 依赖外部 Embedding 或 LLM。`answer` 字段是召回片段形成的可审计抽取式答案，不代表某个具体模型的生成质量；它用于先锁定“有没有召回正确事实”和“回答是否带来源”，真实模型的最终措辞质量仍需部署环境抽样复测。

固定验收阈值：

- 12 个样例必须全部存在且 ID 唯一。
- `catalog` 来源召回率为 1，但不伪造答案质量分数。
- `auto` 与 `tool` 的来源召回率、事实覆盖率、来源引用率均为 1。
- 任一错误来源或缺失事实都会在逐题结果中暴露。
